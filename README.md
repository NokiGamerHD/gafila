# GaFila - Sua vez, sem fila
## Sistema de Web Gerenciamento de Filas
## Projeto desenvolvido durante a Hackthon da Etec de Peruíbe, durante o ano de 2026.


## Funcionalidades:
- Entrada na fila principal;
- Fila de repetição;
- Criação de contas individuais.
