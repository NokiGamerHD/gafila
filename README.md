# GaFila - Sua vez, sem fila
## Sistema de Web Gerenciamento e Organização de Filas
## Projeto desenvolvido durante a Hackthon da Etec de Peruíbe, durante o ano de 2026.
  GaFila é um website mobile-first que susbtitui as filas físicas 
desordenadas da merenda por um sistema digital de senhas em tempo real.
Alunos entram na fila pelo celular e são notificados quando é a vez deles.

## Funcionalidades
- Fila em tempo real;
- Dois tipos de fila, principal e repetição;
- Notificação instantânea;
- Painel dos funcionários;
- Criação de contas por RM, CPF/RG;
- Login como visitante.

## Fluxo de uso
  Para o Aluno:
  Aluno acessa o site --> Registra-se/Faz login como aluno, ou entra como 
visitante --> Pressiona "Entrar na Fila" --> Recebe um senha --> acompanha 
posição em tempo real --> Notificado quando é chamado --> Fila de repetição 
é liberada.

  Para os funcionários:
  Funcionário acessa o site --> Registra-se/Faz login como funcionário --> 
Vê o painel com "Fila Principal" e "Fila de Repetição" --> Pressiona 
"Chamar próximo" para avançar a fila.
